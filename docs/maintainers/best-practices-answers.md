# OpenSSF Best Practices answer sheet

Project page: https://www.bestpractices.dev/projects/15771 (badge: `https://www.bestpractices.dev/projects/15771/badge`).

Enter each answer on the project page, one level at a time. The URLs point at `main`, so enter the answers after the
pull request that adds these files has merged. Where a justification starts with **MAINTAINER**, the criterion asks
for a statement only a maintainer can make (for example "most reports got a response"). Check it is true before you
select Met. Rows marked **NEEDS A DECISION** need a project decision first.

Check progress at any time:

```bash
curl -s https://www.bestpractices.dev/projects/15771.json \
  | python3 -c "import json,sys; d=json.load(sys.stdin); print(d['badge_percentage_0'], d['badge_percentage_1'], d['badge_level'])"
```

Silver builds on Passing, so finish Passing first. Gold is out of scope for now: it needs a second unassociated
contributor, a bus factor of 2, two-person review on every change, enforced 2FA and a third-party security review.
