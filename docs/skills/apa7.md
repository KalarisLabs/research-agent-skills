# `apa7`

**Category:** [journal-formats](/skills#journal-formats) · **License:** MIT · **Version:** 1.0

**Tags:** APA 7, APA style, citations, references, psychology, social sciences, thesis formatting

## When to use it

Format papers, theses and references in APA Style 7th edition for psychology, education, social sciences, nursing and business, covering student vs professional papers, title page, abstract and keywords, heading levels, in-text citations, reference list entries (journal articles, books, chapters, datasets, software, webpages, AI tools), tables and figures, bias-free language, and APA via LaTeX (apa7 class + biblatex-apa), Word or Pandoc/CSL. Use when a user needs APA format, APA citations or references, or an APA-compliant manuscript or thesis.

## Example requests

Ask your agent in plain language, for example:

- *"Convert my reference list to APA 7th edition and fix the heading levels in my thesis."*
